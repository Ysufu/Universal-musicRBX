## ✨ Fitur

### 🎨 UI / Tampilan
- **Spotify-Style Design** — Dark theme (#121212), green accent (#1DB954)
- **Album Art** — Icon musik di setiap lagu
- **Progress Bar** — Seek & drag untuk lompat ke bagian lagu
- **Volume Slider** — Atur volume 0-100%
- **Search Bar** — Cari lagu by judul, artist, atau ID
- **Smooth Animations** — Hover effect di playlist
- **Draggable** — UI bisa digeser kemana aja

### 🎵 Player
- **Play / Pause / Stop** — Kontrol lengkap
- **Next / Prev** — Skip lagu
- **Shuffle** — Random mode
- **Loop** — Repeat lagu yang sama
- **Auto-Next** — Lanjut otomatis pas lagu habis
- **Volume Control** — Slider + preset

### 🌐 Universal
- **Works di SEMUA game Roblox** — Gak peduli genre / map
- **Multi-Parent Fallback** — UI & Sound otomatis cari lokasi terbaik
- **Handle Respawn** — Sound auto-recreate pas karakter mati
- **Anti-Crash** — Pcall di mana-mana
- **Config Persistence** — Setting tersimpan otomatis

### 💾 Config
- **Auto-Save** — Volume, Loop, Shuffle, UI State tersimpan
- **Per-Device** — File config di folder executor
- **Reset Option** — Bisa reset ke default
